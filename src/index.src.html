OPEN-SOURCE SOFTWARE

  • DOI 10.5281/zenodo.22087230 MIT · 2025 – Present

    pygeofetch — Unified Satellite Data & Processing

    Federated search and resumable, checksum-verified download across 22 providers; STAC / GeoParquet export; 17 spectral indices; and a full Sentinel-1 InSAR chain through to SBAS time series.

    PyPI Docs
  • DOI 10.5281/zenodo.22258220 MIT · Pre-alpha

    pygeovision — End-to-End Geospatial AI

    From a bounding box and a date to a finished map: 51 pipelines, 119+ architectures, EO foundation models (Prithvi-EO-2.0, DINOv3, SAM) and a FastAPI inference server with ONNX, Jetson and cloud deployment.

    PyPI Docs
  • DOI 10.5281/zenodo.22209219 MIT · Pre-alpha

    pyunwrap — Regime-Aware InSAR Phase Unwrapping

    AmbiguityNet predicts the integer phase ambiguity, so output always re-wraps to the input; 99.1% exact cycles on easy and 96.6% on moderate synthetic test scenes. Each region is routed to SNAPHU or the learned model, whichever benchmarks stronger.

    Case study PyPI
  • DOI 10.5281/zenodo.22706887 MIT · Pre-alpha

    ps-gnn — Graph Neural Networks for PS Selection

    Persistent-scatterer selection reframed as node classification: GCN, 8-head GAT and GraphSAGE over a 19-feature node vector. F1 0.82 vs 0.69 for StaMPS-style selection on hard synthetic test scenes.

    Case study PyPI
  • github.com/EOCoreINT Toolkit

    Geospatial Data-Engineering Toolkit

    raster2pm (GeoTIFF → PMTiles, tested on 64 GB orthomosaics), geoviz, geo-repair, pygeoproof, geoshift, geo-auto-train and pygeospace for 2D and true-3D visualisation.

Earth Observation Core Intelligence — “From Satellite Data to Decisions.”

An open-source EO software organisation and learning academy teaching applied remote sensing and GeoAI to African students and professionals with open tools.
